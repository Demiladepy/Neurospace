# 🧠 NeuroSpace

> **Empowering Neurodivergent Minds through AI.**
> A WhatsApp-based AI assistant designed to support individuals with Dyslexia and Autism by decoding complex text and analyzing social/emotional contexts.

![Status](https://img.shields.io/badge/Status-Development-green) ![Stack](https://img.shields.io/badge/Stack-Llama%20|%20WhatsApp%20|%20SAM%20|%20DINOv3-blue)

## 📖 Overview

**NeuroSpace** is an accessible AI companion that lives where users already are: **WhatsApp**. By leveraging advanced Large Language Models and Computer Vision, it bridges the gap between complex information and neurodivergent processing styles.

### 🌟 Key Features

* **The Decoder (Dyslexia Support):**
    * Users send photos of dense text (textbooks, documents).
    * NeuroSpace OCRs the image and uses **Llama 3** to rewrite the content into simple, dyslexia-friendly language.
* **Emotion Sentinel (Autism Support):**
    * Users send photos of social situations or facial expressions.
    * Using **DINOv3** and **Llama 3**, the system analyzes the image to provide context on emotions and social cues.
* **Object & Routine Assistant:**
    * Uses **SAM (Segment Anything Model)** to isolate objects in a chaotic environment (e.g., a messy room) to help users focus on specific tasks or find items.

## 🛠️ Tech Stack

| Component | Technology | Role |
| :--- | :--- | :--- |
| **LLM Engine** | **Llama 3 (via Groq)** | Text simplification, reasoning, and empathetic chat responses. |
| **Interface** | **WhatsApp Business API** | The frontend interface. No new app download required. |
| **Vision (Segmentation)** | **SAM (Segment Anything)** | Isolating specific objects/text blocks from complex backgrounds. |
| **Vision (Understanding)** | **DINOv3 / DINOv2** | Deep visual feature extraction for understanding image context. |
| **Backend** | **FastAPI (Python)** | Handling webhooks, API routing, and logic integration. |
| **Tunneling** | **Ngrok** | Exposing the local server to Meta for webhooks during dev. |

## 🚀 Getting Started

### Prerequisites

* Python 3.9+
* A Meta Developer Account (for WhatsApp API)
* A Groq Cloud API Key
* Ngrok installed

### 1. Clone the Repository
```bash
git clone [https://github.com/yourusername/neurospace.git](https://github.com/yourusername/neurospace.git)
cd neurospace

pip install fastapi uvicorn requests groq python-dotenv transformers torch torchvision
# Meta / WhatsApp
WHATSAPP_TOKEN="your_meta_access_token_here"
PHONE_NUMBER_ID="your_phone_number_id_here"
WEBHOOK_VERIFY_TOKEN="neurospace_secret_token_2025"

# AI Models
GROQ_API_KEY="gsk_your_groq_key_here"
HF_TOKEN="your_huggingface_token_if_needed"

uvicorn main:app --reload

ngrok http 8000


Copy the https URL generated by Ngrok (e.g., https://random-name.ngrok-free.app).

6. Configure WhatsApp Webhook
Go to the Meta App Dashboard.

Navigate to WhatsApp > Configuration.

Click Edit under Callback URL.

Callback URL: YOUR_NGROK_URL/webhook

Verify Token: neurospace_secret_token_2025 (Must match your .env).

Click Verify and Save.

🧠 Usage
Open WhatsApp and message the test number provided by Meta.

Text Mode: Send a complex paragraph. NeuroSpace will reply with a simplified version.

Vision Mode: Send an image.

If it contains text, it triggers The Decoder.

If it contains a scene/face, it triggers Emotion Sentinel.
